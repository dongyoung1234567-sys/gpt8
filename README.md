# gpt8

프로젝트 목적과 기술 스택은 아직 정해지지 않았습니다. 이 저장소는 아이디어와 작업 내용을 정리하는 출발점입니다.

## 지금 바로 사용할 수 있는 3가지

1. **아이디어 기록** — GitHub Issues에서 새로운 아이디어를 등록하고 배경, 기대 효과, 궁금한 점을 적습니다.
2. **할 일 관리** — Issues에 해야 할 일을 한 건씩 작성하고, 진행 상황을 댓글과 완료 처리로 관리합니다.
3. **변경 사항 기록** — README와 문서를 수정할 때 커밋 메시지에 변경 이유를 남겨 작업 이력을 확인합니다.

## 현재 상태

- 프로젝트 목적: 미정
- 기술 스택: 미정
- 기본 브랜치: `main`

프로젝트 방향이 정해지면 이 README에 목표, 실행 방법, 기술 스택을 추가합니다.
